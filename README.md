# NetHunter Terminal NP3

Форк [NetHunter Terminal](https://gitlab.com/kalilinux/nethunter/apps/kali-nethunter-term)
(`com.offsec.nhterm`) — термінала Kali NetHunter, що, своєю чергою, базується на NeoTerm.

---

## Чим цей форк відрізняється

### Повноекранний режим займає й зону камери

В оригіналі з увімкненим **Full Screen** вікно вкладається нижче вирізу камери, і над терміналом
лишається чорна смуга. У форку:

- у портреті верхній бар стоїть на самому верху екрана, а камера опиняється всередині нього;
- у ландшафті інтерфейс так само заходить під камеру збоку;
- коли бар схований, термінал займає всю висоту, включно з рядком камери.

Як зроблено: вікно в Full Screen отримує `layoutInDisplayCutoutMode = SHORT_EDGES`. Додатково
слухач відступів на `DecorView` прибирає виріз зі «старих» системних відступів
(`systemWindowInsets`): Android включає в них виріз, і без цього контейнери з `fitsSystemWindows`
однаково відсували б увесь вміст на висоту вирізу. Відступи навігаційної панелі та клавіатури
лишаються як були.

`FullScreenHelper` тепер рахує висоту вмісту від верху вікна, а не від верху видимої області.
Видима область починається під вирізом, тож інакше між терміналом і клавіатурою лишалась
порожня смуга завбільшки з виріз.

### Бар ховається з клавіатурою лише з увімкненим «Hide Toolbar»

Оригінал у Full Screen ховав верхній бар при кожному відкритті клавіатури, навіть коли
**Hide Toolbar** вимкнено. Тепер бар ховається тільки з цією опцією. Тоді термінал розтягується
на всю висоту, а після закриття клавіатури бар заїжджає назад.

### Додаткові кнопки вмикаються й вимикаються одразу

- Перемикач **Show extra keys** діє на вже відкриті сесії, без перезапуску. Раніше кожна сесія
  запам'ятовувала налаштування в момент створення.
- Нова вкладка (наприклад, кастомна команда із застосунку NetHunter) одразу створюється з
  кнопками за налаштуванням. Вимкнені кнопки більше не блимають на початку, поки сесія не
  отримала заголовок.

### Нова опція «Close on exit»

**Settings → UI → Close on exit** (за замовчуванням вимкнена):

- шелл, що завершився звичайно (`exit`, код 0), одразу закриває свою вкладку. Якщо код
  ненульовий, вкладка лишається з `[Process completed (code N)]`, щоб можна було прочитати вивід;
- після закриття останньої вкладки (через інтерфейс, меню чи `exit`) застосунок закривається
  повністю й зникає з недавніх, а не лишається з порожнім списком вкладок.

> Якщо застосунок NetHunter запускає в терміналі скрипт, що завершується з кодом 0, з цією
> опцією вкладка закриється разом із виводом.

## Збірка

Потрібні JDK 17, Android SDK, NDK `29.0.14206865` і CMake `4.1.2`. Версії NDK і CMake задано в
`nhterm/build.gradle`; якщо у вас інші, змініть їх там.

```bash
./gradlew :nhterm:assembleRelease
```

Release-збірка виходить непідписаною
(`nhterm/build/outputs/apk/release/nhterm-release-unsigned.apk`). Підпишіть її **власним**
ключем через `apksigner`.

> ⚠️ Не підписуйте збірку ключем `nhterm/nethunter-debug.jks` з репозиторію. Він публічний разом
> із паролем: будь-хто зможе підписати ним «оновлення», і воно встановиться поверх, отримавши дані
> терміналу та його root-дозвіл у Magisk.

## Встановлення замість версії з NetHunter Store

Версія зі Store підписана ключем NetHunter Store, тож власна збірка поверх неї не стане. Порядок:

1. Забекапте дані терміналу (root): `/data/data/com.offsec.nhterm` — налаштування, профілі,
   кольорові схеми, шрифти.
2. Видаліть версію зі Store: `pm uninstall com.offsec.nhterm`.
3. Встановіть свою збірку.
4. Якщо треба, поверніть дані. Новій установці дістанеться новий UID: виправте власника
   (`chown -R`) і SELinux-контекст (`chcon -R`, як у теки застосунку) відновлених файлів.
5. Під час першого запиту root Magisk спитає дозвіл знову, бо попередній був прив'язаний до старого UID.

Оновлення терміналу зі Store після цього не встановлюватимуться (інший підпис). Наступні власні
збірки ставляться поверх (`adb install -r`), і дані зберігаються.

# Оригінальний опис (NetHunter-Terminal)

* A modern-designed android terminal emulator for the 21st century based on NeoTerm.

#### Main changes that have been done

* Implement kali sessions
* Include in-app:
  * scripts for fast kali chroot ( even if not mounted by bootkali )
  * static bash for android sessions ( + root too )
  * scripts to launch android( + -su) sessions
* Function to reset/restore in-app assets if something breaks from editing ( Can be done in About -> Reset App )
* Additional fonts and color schemes
